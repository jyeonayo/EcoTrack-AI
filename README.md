# EcoTrack AI

자동차 배출가스 CSV를 분석하고 Isolation Forest로 이상 패턴을 탐색하는 Streamlit 웹 앱입니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 기능
- 배출가스 측정 CSV 업로드 및 열 선택
- CO, HC, CO2, NOx, O2 등의 분포와 기초 통계
- Isolation Forest 기반 비지도 이상 패턴 탐지
- 기준 CSV 미리보기 및 사용자가 입력한 기준값과 측정값 비교
- 결과 CSV 다운로드

## 데이터 해석상 주의
AI 이상 패턴 탐지는 법적 위반이나 차량 고장을 판정하지 않습니다. 실제 정답 라벨이 없는 측정 데이터에 대해 비지도 학습을 적용한 것입니다. 탐지 비율 설정값은 실제 이상 차량 비율이 아닙니다.

무부하검사, 부하검사(ASM-Idling·KD-147), 제작차 인증시험, 도로 원격측정(RSD)은 서로 다른 측정 방식입니다. 측정 방법, 차량 조건, 단위가 일치하는 경우에만 기준 비교를 수행해야 합니다. 제작차 인증 기준과 운행차 검사 기준도 서로 대체할 수 없습니다.

기준표를 업로드해도 법적 기준이 자동으로 연결되지는 않습니다. 공식 기준 자료에서 해당 차량과 검사 방식에 맞는 값을 확인한 뒤 입력해야 합니다.

개인정보 또는 차량번호가 포함된 원본 데이터는 공개 GitHub 저장소에 업로드하지 마세요. 익명화된 자료만 사용하세요.
